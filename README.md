# Visual Choice

Контент сканері: әлеуметтік желідегі скриншоттардағы манипуляция белгілерін табады.
«Контентті талдау және жастардың медиа сауаттылығын арттыру» тақырыбындағы оқушының ғылыми жобасы.

Скриншот браузердің ішінде танылады (Tesseract.js, қазақ тілі моделі), сурет ешқайда жіберілмейді.
